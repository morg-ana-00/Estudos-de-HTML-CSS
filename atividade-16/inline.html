Diferença entre Elementos Block e Inline

1. Elementos do Tipo Block

<h2> - Eu sou um elemento de BLOCO! (Ocupo a linha inteira)

<p> - Eu também sou de BLOCO! Mesmo que meu texto seja curto, nenhum elemento fica ao meu lado.

<div> - Sou o bloco genérico mais utilizado para agrupar outros elementos.

2. Elementos do Tipo Inline

Abaixo temos elementos que ficam lado a lado na mesma linha:

Texto normal -> <span> (Texto genérico inline) <strong> (Texto importante em negrito) <a> (Link inline para o W3Schools)

Painel de Gerenciamento do Sistema

Utilize os botões abaixo para realizar ações de simulação no sistema:

Função: Abre o formulário para inclusão de um novo usuário no banco de dados.

Função: Permite alterar as informações e preferências do usuário selecionado.

Função: Remove permanentemente o registro do sistema. (Clique para testar o alerta JS).

Função: Cancela a operação atual e retorna para a tela inicial.

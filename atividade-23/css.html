Minha Primeira Página Estilizada

HTML e CSS trabalham em conjunto: enquanto o HTML cria a estrutura e o conteúdo da página, o CSS fica responsável por dar vida a página ex:(design, layout, cores e tipografia).

Este bloco está sendo estilizado com CSS Interno dentro da tag <style> no cabeçalho.

Este parágrafo utiliza CSS Inline (estilo direto no atributo style da tag).
